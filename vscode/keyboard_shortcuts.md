# VS Code Keyboard Shortcuts

> Quick-reference guide for everyday development in Visual Studio Code.
>
> **Platform:** Windows / Linux keyboard notation

---

## File & Explorer

| Shortcut | Action |
|---|---|
| `Ctrl + N` | New File |
| `Ctrl + O` | Open File |
| `Ctrl + S` | Save File |
| `Ctrl + Shift + S` | Save As |
| `Ctrl + P` | Quick Open |
| `Ctrl + Shift + E` | Show Explorer |
| `Ctrl + K`, then `Ctrl + O` | Open Folder |

---

## Search & Find

| Shortcut | Action |
|---|---|
| `Ctrl + F` | Find in File |
| `Ctrl + H` | Replace in File |
| `Ctrl + Shift + F` | Find in Files |
| `Ctrl + Shift + H` | Replace in Files |
| `F3` | Find Next |
| `Shift + F3` | Find Previous |
| `Ctrl + D` | Select Next Match |
| `Ctrl + K`, then `Ctrl + D` | Skip Selection |

---

## Editing

| Shortcut | Action |
|---|---|
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `Ctrl + X` | Cut Line |
| `Ctrl + C` | Copy Line |
| `Ctrl + V` | Paste |
| `Alt + ↑` | Move Line Up |
| `Alt + ↓` | Move Line Down |
| `Shift + Alt + ↑` | Copy Line Up |
| `Shift + Alt + ↓` | Copy Line Down |
| `Ctrl + /` | Toggle Line Comment |

## Multi-Cursor & Selection

| Shortcut | Action |
|---|---|
| `Ctrl + D` | Select Next Occurrence |
| `Ctrl + Shift + L` | Select All Occurrences |
| `Alt + Click` | Add Cursor |
| `Ctrl + Alt + ↑ / ↓` | Add Cursor Above / Below |
| `Ctrl + L` | Select Current Line |
| `Ctrl + Shift + L` | Select All Lines / Matching Occurrences |
| `Ctrl + Shift + →` | Expand Selection |
| `Ctrl + Shift + ←` | Shrink Selection |

> Some selection shortcuts can vary by operating system or VS Code keymap.
